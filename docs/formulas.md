# 기본 공격 실험 계산 규칙

이 문서는 UI 이전의 기본 공격·스탯 비교 도구를 위한 근거와 적용 범위를 기록한다.
검토 기준일: 2026-09-09. 실제 게임 데이터 스냅샷은 아직 저장하지 않았다.

## 확인한 공식 자료

- [공식 Open API 문서, 2026-07-24](https://developer.eternalreturn.io/static/media/OpenAPI_KR_20260724.html): 게임 데이터 조회 경로와 테이블을 제공한다. 이 문서만으로 스탯 합산 및 피해 적용 순서를 확정할 수는 없다.
- [8.0 메인 패치, 2025-07-10](https://playeternalreturn.com/posts/news/2827?hl=ko-KR): 쿨다운 식 `최초 쿨다운 × 100 / (100 + 쿨다운 감소 합계)`를 제시하며 방어력 공식과 동일한 형태라고 설명한다. 아래 방어식은 이 설명에서 도출한 **해석**이며, 현재 패치의 완전한 피해 공식으로 확인한 것은 아니다.
- [1.17 패치, 2024-03-14](https://playeternalreturn.com/posts/news/1792?hl=ko-KR): 당시 기본 치명타 피해를 165%에서 175%로 변경했다. 과거 패치값을 현재 기본값으로 하드코딩하지 않는다.
- [12.3 패치, 2026-09-03](https://playeternalreturn.com/posts/news/3813?hl=ko-KR): 조사 시 확인한 패치 출처이다. 최신 데이터 및 모든 후속 핫픽스 검증을 의미하지 않는다.

## 승인된 최소 실험 모델

규칙 ID: `basic-attack-experiment-v1`. 상태: **사용자 승인 임시 모델**.
2026-09-09 사용자가 기초 모델에 무기 숙련도 레벨별 기본 공격 증폭을 포함하는 조건으로
승인했다. 이 표의 식은 공식 확정식이 아니며, 해당 실험 범위에만 적용한다.

| 단계 | 제안된 실험식 | 제한 |
| --- | --- | --- |
| 영구 스탯 | `기본값 + 레벨당 성장값 × (레벨 - 1) + 고정 추가값들의 합` | 공격력·방어력·최대 체력만. 비율 수정·변환·숙련도 자동 계산 미지원 |
| 기본 공격 증폭 | `무기 숙련도 레벨 × 입력한 레벨별 증폭률` | 증폭률은 소수 비율. 2%이면 0.02. 캐릭터 레벨과 구분 |
| 일반 기본 공격 | `공격력 × (1 + 기본 공격 증폭)` | 별도 계수·추가타·패시브가 없는 단일 타격에 한정 |
| 치명타 기본 공격 | `일반 기본 공격 피해 × 입력한 최종 치명타 배율` | 1.75 등의 기본값을 넣지 않음. 배율을 직접 명시 |
| 방어 적용 | `방어 적용 전 피해 × 100 / (100 + 방어력)` | 방어력 0 이상, 관통·피해 증폭·감소 없음 |

숫자 예시: 최종 공격력 100, 무기 숙련도 10, 레벨별 증폭률 0.02,
방어력 100이면 일반 공격 60을 예상한다.
최종 치명타 배율을 1.75로 **입력한 실험**에서는 치명타 105를 예상한다.
이 숫자는 수학적 예시이며 특정 실험체의 실제 데이터가 아니다.

단일 실측과 대조하기 위해 각 공격의 일반/치명타 여부는 입력에 명시한다.
치명타 확률은 입력 스탯을 보존하고 출력하되 난수를 추첨하지 않는다.
따라서 결과는 **명시한 치명타 발생 조건에 대한 피해**이며 확률 가중 기대 피해가 아니다.
확률 0에서 치명타 또는 확률 1에서 일반 적중을 입력하면 오류로 처리한다.
치명타 이력 보정을 적용하지 않는 기존 승인 임시 가정은 유지한다.

공격 속도는 게임에서 확인한 최종 초당 공격 횟수를 직접 입력한다.
입력한 공격 간격이 이 속도보다 빠르면 오류를 표시한다.
선후딜·투사체·이동·공격 초기화·다단 기본 공격의 실행 가능성은 검증하지 못한다.
첫 타격 시간을 자동 생성하지 않고 사용자가 지정한 정수 밀리초 목록을 사용한다.

## 이미 사용자 지정으로 확정된 집계 규칙

근거: 프로젝트 `AGENTS.md` 5·6절.

- 빗나감의 적중 피해는 0이다. 빗나간 공격도 행동 간격 검증에는 포함된다.
- 보호막 피해와 체력 피해를 분리하며 총 피해는 두 항목의 합이다.
- 체력 피해에는 초과 피해를 포함하고, 사망 이후에도 명시한 구간의 공격을 계산한다.
- 계산상 잔여 체력은 음수가 될 수 있다. 조건 판정용 현재 체력은 `max(0, 잔여 체력)`이다.
- `combo_dps = 총 피해 / 명시된 측정 구간(초)`이다.
- 매 실행은 별도 상태에서 시작하고, 입력 스탯을 전투 중 변경하지 않는다.
- 중간 결과를 정수로 절삭하지 않는다. 실제 게임의 반올림 규칙은 미확정이다.

## 실험 결과의 해석

실측치는 계산식 입력으로 역주입하지 않는다. `예상값 - 실측값`의 부호 있는 오차와
실측값 기준 오차율을 별도로 출력한다. 실측값이 0이면 오차율은 정의하지 않는다.
실측이 없는 타격은 미측정으로 남기고 전체 실측 합계와 비교하지 않는다.
부분 측정은 측정된 타격끼리의 합계만 비교한다.

캐릭터·장비·특성·레벨·숙련도·초기 버프·모드·패치를 기록해야 실험을 재현할 수 있다.
아직 API의 장비/특성/숙련도 데이터를 자동으로 불러오는 기능은 없다.
장비의 고정 수치와 무기 숙련도 레벨별 증폭률은 출처와 함께 직접 입력한다.
지원 범위 밖의 효과가 있는 조건은 이 최소 모델과 비교 가능한 것으로 표시하지 않는다.
샘플은 합성 fixture이며, 실제 게임값을 검증했다고 해석하지 않는다.
