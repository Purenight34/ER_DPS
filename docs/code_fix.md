# 게임 실험값과 계산 결과 비교

현재 규칙: `basic-attack-experiment-v1` (사용자 승인 임시 모델).
아직 사용자가 제공한 실제 게임 측정값은 없다. `examples/basic_attack.ini`와 테스트의 수치는
합성 fixture이며 실제 실험 성공 사례로 취급하지 않는다.

## 실험 기록 양식

실험마다 아래 항목을 복사해 새 기록을 추가한다.

- 실험 ID / 측정 일시:
- 게임 패치 / 핫픽스 / 모드:
- 데이터 버전 / 출처 / 확보 일시:
- 계산 규칙 버전:
- 입력 시나리오 파일 / 결과 JSON 파일:
- 공격자 캐릭터·무기·장비·특성·레벨·스킬 레벨·숙련도:
- 방어자 캐릭터·무기·장비·특성·레벨·스킬 레벨·숙련도:
- 양측 초기 효과·스택·버프·체력·보호막:
- 게임에서 확인한 공격력·방어력·최대 체력·공격 속도·치명타 확률·최종 치명타 배율:
- 무기 숙련도 레벨 / 레벨별 기본 공격 증폭률 및 출처:
- 기본값·성장값·장비 고정 수치의 출처:
- 측정 시작과 종료 / 공격 시각·ID / Hit·Miss / 각 공격의 치명타 여부:
- 비교 불가능하게 만드는 추가 효과 / 아직 빠진 조건:

| 공격 ID | 관측 보호막 피해 | 관측 체력 피해 | 관측 총 피해 | 계산 총 피해 | 계산−관측 | 관측 방법 |
| --- | --- | --- | --- | --- | --- | --- |
| 작성 전 | | | | | | |

관측하지 못한 항목은 미측정으로 둔다. 피해 숫자 표시와 전후 체력 차이는
반올림·회복·보호막 등으로 다를 수 있으므로 관측 방법을 함께 기록한다.
사망 이후 남은 체력은 게임의 사망 처리와 직접 비교하는 지표가 아니라 콤보 초과 피해 기록이다.

## 차이 분석과 가설

1. 누락 조건 및 버전 불일치를 확인한다. 누락값은 추측해 채우지 않는다.
2. 스탯 계산과 피해 계산 중 어느 단계부터 달라지는지 계산 내역으로 구분한다.
3. 각 가설의 계산 과정, 설명하는 관측값과 설명하지 못하는 관측값을 기록한다.
4. 가설을 구분할 추가 실험을 제안한다. 한 점에 맞게 상수를 조정하지 않는다.
5. 새 비공식 근거 또는 추정 규칙을 반영하기 전에 사용자 승인을 기록한다.
6. 승인된 변경은 적용 범위와 규칙 버전을 갱신하고 재현 테스트를 추가한다.

| --- | --- | --- | --- | --- | --- | --- |
| 작성 전 | | | | | 미제안 | |

## 승인 기록

- 2026-09-09: 사용자가 기본값·레벨 성장·고정 추가 스탯 합산과 기초 평타·치명타·비음수 방어의
  최소 실험 모델을, 레벨별 기본 공격 증폭 포함 조건으로 승인했다.
- 같은 대화에서 레벨 기준이 **무기 숙련도 레벨**임을 확인했다.
- 결과는 명시한 일반/치명타 발생 조건에 대한 값이다. 게임 난수 및 치명타 이력 보정은 구현하지 않는다.
- 관통·별도 피해 증폭/감소·추가 타격·패시브·모드 보정은 승인 범위에 포함되지 않는다.

## 남은 검증

- 실제 캐릭터 및 장비 데이터로 스탯과 일반 기본 공격 대조
- 무기 숙련도 레벨별 증폭률과 합산 기준 대조
- 현재 패치 치명타 스탯의 단위와 일반/치명타 관측 대조
- 게임의 중간 절삭·반올림 및 화면 표시 규칙 확인
- 캐릭터별 기본 공격 계수·다단 타격·공격 간격 예외
- 기본 공격의 공식 ID와 게임 데이터 버전 캐시 연결
